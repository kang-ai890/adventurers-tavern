# 🚀 上线部署清单（跟着做就能免费上线）

> 当前状态：项目骨架已在本地跑通（构建 ✅ / 类型检查 ✅ / 后端启动 ✅ / Socket.IO 联机握手 ✅）。
> 下面 5 步全部免费，做完游戏就上线了。

---

## 第 1 步：推送到 GitHub（约 5 分钟）

1. 注册/登录 [github.com](https://github.com)，右上角 **+ → New repository**；
2. Repository name 填 `adventurers-tavern`，**Public**，不要勾选初始化文件（README 已有），创建；
3. 本地执行（把 `你的用户名` 换成你的 GitHub 用户名）：

```bash
git config user.name "你的用户名"
git config user.email "你的GitHub邮箱"
git remote add origin https://github.com/你的用户名/adventurers-tavern.git
git push -u origin main
```

推送后，仓库 `.github/workflows/ci.yml` 会自动跑一遍构建验证（绿色 ✓ 即成功）。

## 第 2 步：创建免费数据库 Neon（约 5 分钟）

1. 打开 [neon.tech](https://neon.tech)，用 GitHub 账号注册登录；
2. 创建项目（名字随意），创建后复制连接串，长这样：

```
postgresql://用户名:密码@xxx-xxxx.aws.neon.tech/neondb?sslmode=require
```

3. 先在本机建表（打开新终端，在项目目录执行）：

```bash
$env:DATABASE_URL = "粘贴你的连接串"
npm run db:deploy      # 执行 Prisma 迁移，创建所有表
```

## 第 3 步：部署后端到 Render（约 10 分钟）

1. 打开 [render.com](https://render.com)，用 GitHub 账号登录；
2. **New → Blueprint**，选中 `adventurers-tavern` 仓库 → 自动读取 `render.yaml`；
3. 环境变量：把 `DATABASE_URL` 的值改成第 2 步的连接串；`JWT_SECRET` 保持自动生成；
4. Create → 等构建部署（约 3~5 分钟），记下服务地址，长这样：

```
https://adventurers-tavern-server.onrender.com
```

> 免费实例无人访问 15 分钟后休眠，冷启动约 1 分钟——游戏登录页已有"唤醒中"提示，正常现象。

## 第 4 步：改前端指向后端（1 分钟）

编辑 `.github/workflows/deploy-pages.yml`，把 `VITE_SERVER_URL` 的值改为你的 Render 地址，提交推送。

## 第 5 步：开启 GitHub Pages

1. 仓库 **Settings → Pages**；
2. Source 选 **GitHub Actions**（会自动识别 `deploy-pages.yml`）；
3. 推送后等 2 分钟，游戏上线地址：

```
https://你的用户名.github.io/adventurers-tavern/        ← 游戏
https://你的用户名.github.io/adventurers-tavern/admin/  ← 管理后台
```

## 常见问题

| 问题 | 处理 |
|---|---|
| Pages 打不开 | Settings→Pages 确认 Source 是 GitHub Actions；等 2 分钟 |
| 游戏一直"唤醒中" | 后端免费实例冷启动，等 1~2 分钟刷新；或 Render 控制台看日志 |
| 连接报错跨域 | Render 环境变量 `CORS_ORIGIN` 改为你的 Pages 域名 |
| 想换域名 | 免费方案可在 Pages 自定义域名 + Render 绑定同一域名子域（如 game.你的域名） |
